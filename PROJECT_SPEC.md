# Project Specification: RepoInsight AI

## Goal
Build a system that transforms a GitHub URL into a comprehensive architectural analysis.

## Core Principle
**Python extracts facts → Ollama interprets relevant context → Python generates final outputs.**

## V1 Supported Frameworks
- FastAPI
- Flask
- Express
- Spring Boot

## Requirements
- Python 3.11+
- Local Ollama instance
- Graphviz installed on the system

## Phases
- Phase 0: Initialization
- Phase 1: Clone and Scan
- Phase 2: Repository Analyzer
- Phase 3: API Analyzer
- Phase 4: DB, Auth, External, Security Analyzer
- Phase 5: Ollama Connection & Context Builder
- Phase 6: Architecture Analysis
- Phase 7: Project Report
- Phase 8: PowerPoint Generation
- Phase 9: Pipeline & FastAPI Backend
- Phase 10: Streamlit UI
- Phase 11: Testing & Hardening
- Phase 12: Final Documentation
